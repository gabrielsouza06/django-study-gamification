## 📖 Sobre o Projeto

O **Django Study Gamification** é uma aplicação web desenvolvida em Python com o framework Django, projetada para aplicar mecânicas de jogos (gamificação) aos estudos diários. O objetivo principal é manter o usuário motivado através de sistemas de pontos de experiência (XP), níveis, conquistas e acompanhamento de tarefas/metas de estudo.

---

## ✨ Funcionalidades Principais

- 👤 **Gerenciamento de Usuários:** Sistema de autenticação (Cadastro, Login e Logout).
- 📚 **Gestão de Matérias/Tópicos:** Organização dos conteúdos e disciplinas que estão sendo estudados.
- 🎯 **Registro de Estudos (Quests):** Adicionas sessões de estudo que convertem o tempo ou conclusão de tarefas em recompensas.
- ⭐ **Sistema de XP e Níveis:** Acúmulo de experiência conforme o progresso nas matérias, subindo de nível de acordo com o rendimento.
- 🏆 **Conquistas/Badges (Em breve/Opcional):** Desbloqueio de medalhas por metas alcançadas.

## 🛠️ Tecnologias Utilizadas

- **[Python](https://www.python.org/)** (v3.10+)
- **[Django](https://www.djangoproject.com/)** (v4.x ou superior)
- **Banco de Dados:** SQLite (padrão para desenvolvimento)
